### How to set-up a vulnerable machine for security testing

- we need to have windows & virutal box installed for this lab, there we can have downloads requriements

#### Downloads
- [virutal-box](https://www.virtualbox.org/wiki/Downloads)
- [metasploitable machine](https://docs.rapid7.com/metasploit/metasploitable-2/)

#### Installation
- install the virtual box & import the metasploitable & set up the ram and storage size

#### usage
- Powering on Metasploitable 2
    Once the VM is available on your desktop, open the device, and run it with VMWare Player. Alternatively, you can also use VMWare Workstation or VMWare Server.

#### default-login
- Logging in to Metasploitable 2
    The login for Metasploitable 2 is `msfadmin:msfadmin`.
